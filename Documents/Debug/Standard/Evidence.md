# 证据标准

## 1. 目的

本文件规定调试中什么算证据、怎样测量、怎样比较、怎样陈述。

它不规定具体指标；指标由问题陈述决定。

## 2. 证据等级

| 等级 | 定义 | 可用于 |
|------|------|--------|
| E0 | 轶事、单次观察、无可复现记录 | 只作线索 |
| E1 | 有环境记录的单次运行 | 形成假设 |
| E2 | 同条件多次运行，给范围 | 判断稳定性 |
| E3 | 对照实验：基线/处理/反事实 | 支持因果候选 |
| E4 | E3 + 机制解释 + 替代解释排除 | 根因判定、修复决策 |

修复决策至少 E3；根因陈述至少 E4。达不到时写「候选」「相关」「未定因」。

## 3. 原始数据

- 原始日志、trace、JSON、控制台输出不可修改；报告是派生视图。
- 每条记录带：时间、版本/提交、配置、开关、实验编号、批次/运行号。
- 失败和异常样本必须保留，不能只留成功样本。
- 数据量大时保留采样规则和丢失计数；`dropped` 大于 0 时样本不完整。
- 不在报告里手工补原始数据里没有的字段。

## 4. 时间与单位

- 区间用单调时钟；墙钟只做关联。
- 记录统一单位（如微秒），报告统一换算（如毫秒），并在文档写明。
- 跨线程时间必须注明时钟来源和同步方式。
- 不把并行区间相加当墙钟时间；并行 span 的重叠要单独说明。
- 队列时间、执行时间、传输时间分开记录，不混为一个「耗时」。

## 5. 统计口径

- 至少报告：样本数、最小值、最大值、中位数；必要时加四分位。
- 重尾分布不用平均值单独下结论。
- 先估计噪声底，再判断处理差异是否大于噪声。
- 异常值不直接删除；说明保留或剔除规则。
- 单次最快值不能代表分布。
- 对照实验保持输入、节流、屏幕状态、服务和宿主负载一致。
- 顺序效应（冷启动、缓存、滚屏、GC）要单独记录或随机化顺序。

## 6. 观测有效性

检查：

- 覆盖：目标路径是否都有观测点；没有的点是否明确标未覆盖。
- 完整性：记录是否被覆盖、丢弃、截断。
- 采样偏差：采样间隔是否与热点同步；是否系统性漏掉短事件。
- 观察者效应：记录、读时钟、序列化、采样本身增加多少开销。
- 语义：事件名、单位、方向、父子关系是否与实现一致。
- 校准：已知答案的测试是否通过；关闭开关是否零记录。
- 一致性：同一事件在不同线程/设备的定义是否一致。

观测有效性不通过时，先修观测，不用数据下结论。

## 7. 因果证据

支持因果至少需要：

1. 时间顺序：原因先于结果。
2. 机制：有可解释的路径。
3. 可重复：同条件重复出现。
4. 反事实：移除原因结果改变，恢复原因结果回来。
5. 替代解释：主要竞争假设被排除。

只有相关性时写「相关」；只有时间窗重叠时写「同窗」，不写「导致」。
没有父/边证据时，不把嵌套或时间包含当成因果。

## 8. 陈述规范

| 情况 | 写法 |
|------|------|
| 直接观测 | 「实测：……，条件……，样本……」 |
| 由观测推出 | 「推断：……，依据……，未直接观测……」 |
| 没有观测点 | 「未覆盖：……，因此不能判断……」 |
| 单次 | 「本次样本：……，不作稳定结论」 |
| 多次 | 「N 次：中位数……，范围……」 |
| 对照 | 「同一实验：基线……，处理……，差异……，噪声底……」 |
| 无差异 | 「未观察到可辨识差异；不能证明无影响」 |

禁止：

- 用「优化完成」「性能提升」替代数字和条件。
- 把单次最好值写成稳定结论。
- 把未覆盖写成正常。
- 把采样次数写成执行次数。
- 把估算时间写成函数自耗时。

## 9. 报告最小字段

```text
实验编号：
问题陈述：
版本/提交：
环境与配置：
开关状态：
输入与节流：
样本数：
原始数据路径：
基线：
处理：
结果范围/中位数：
噪声底：
对照/反事实：
结论等级：E0–E4
限制与未覆盖：
下一步：
```

## 10. 负结果

负结果必须记录：

- 候选被证伪的条件。
- 回退的版本和原因。
- 没有差异的范围。
- 仍然未知的部分。

负结果避免重复劳动，和正结果同等重要。

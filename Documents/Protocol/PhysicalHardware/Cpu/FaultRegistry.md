# ZCP1 指令失败登记表（Fault Registry）

> 路径：`Documents/Protocol/PhysicalHardware/Cpu/FaultRegistry.md`  
> 所属协议：`ZCP1`（见 [ZCP1.md](./ZCP1.md) §4.11）  
> 规范状态：**规范性（登记）**  
> 配套索引：[FaultIndex.md](./FaultIndex.md)  
> 权威优先级：本登记表 > [FaultIndex.md](./FaultIndex.md) > [ZCP1.md](./ZCP1.md) 摘要

## 0. 文档定位

本文登记指令序列停止时必须留下的两个整数：错误码 `Code`、来源 `Source`。

- 约束对象：声称兼容 ZCP1、并在指令失败时留下失败记录的实现。
- 面板上的字形只接受 `0x20` 至 `0x7E`。`Text` 的渲染规则在 ZCP1 §4.11，不在本表逐字登记每一句概述。
- 未登记的错误码或来源禁止当作已定义含义使用。尚未归类时错误码必须用 `0`。

## 1. 编码规则

| 规则 | 要求 |
|------|------|
| 空间 | `0` 至 `65535`（含两端） |
| 分配 | 新标号按升序追加，禁止复用已登记号作他义 |
| 记法 | 十进制整数 |

## 2. 错误码

| 标号 | 规范短名 | 含义 | 状态 |
|------|----------|------|------|
| `0` | `Unspecified` | 失败已经发生，但没有更具体的已登记错误码 | 已登记 |
| `1` | `JumpOutOfRange` | 跳转编号不在当前这段指令文本里 | 已登记 |
| `2` | `RegisterIndex` | 寄存器编号不在 `0` 至 `7`，或寄存器里的整数不能用于该命令 | 已登记 |
| `3` | `CoreNotRunning` | 核心不是执行中，仍被要求执行命令 | 已登记 |
| `4` | `CoreBusy` | 上一条命令尚未完成 | 已登记 |
| `5` | `HertzOutOfRange` | Hz 不是 `1` 至 `1000000000` 的整数 | 已登记 |
| `6` | `BadOpcode` | 访存操作码与读或写不匹配，或不在操作码表内 | 已登记 |
| `7` | `MetricKind` | 指标种类不是 `0` 或 `1` | 已登记 |
| `8` | `Exchange` | 扩展口交换被拒绝 | 已登记 |
| `9` | `Query` | 查询的座位、字段或下标没有登记，或该次读取失败 | 已登记 |
| `10` | `Gpu` | 显卡拒绝了这一条命令 | 已登记 |
| `11` | `Memory` | 存储端口拒绝了这一次访问 | 已登记 |
| `12` | `Install` | 装入被拒绝。目标不是另一颗已挂载且停止的核心，地址未按 `8` 对齐，长度不是非负整数，读取被拒绝，八位组不是一次完整的程序映像，或映像是动态库 | 已登记 |
| `13` | `Bound` | 访存越出该核心的可访问范围，或 `bound` 的参数不合法 | 已登记 |
| `14` | `Schedule` | `schedule` 被拒绝。目标没有程序、调用者不是监督核，或系统调用还没有回复 | 已登记 |
| `15` | `Pass` | `pass` 被拒绝。目标未挂载，或保持位已经有值 | 已登记 |
| `16` | `Syscall` | `svc` 被拒绝。没有监督核、调用者就是监督核，或服务号超出 `0` 至 `4294967295` | 已登记 |
| `17` | `Gate` | `gate` 被拒绝。已经有监督核 | 已登记 |
| `18` | `Release` | `release` 被拒绝。调用者不是监督核，或目标未停止、未挂载、就是调用者自己 | 已登记 |
| `19` | `Slice` | `slice` 的条数不是 `0` 至 `4294967295` | 已登记 |
| `20` | `Context` | `capture` 或 `restore` 被拒绝。调用者不是监督核，目标未停止、未挂载、就是调用者自己，槽号不是 `0` 至 `7`，目标没有程序，槽是空的，或放回的私有写入被拒绝 | 已登记 |
| `21` | `Attach` | `attach` 被拒绝。调用者不是监督核，目标未停止、未挂载、就是调用者自己或还没有程序，映像不是动态库，导入对不上，导出名字有的已经在有的不在，重定位越出接好的序列，或八位组不是一次完整的程序映像 | 已登记 |

`22` 起尚未登记，禁止当作已定义含义使用。

## 3. 来源

来源表示失败被归到哪一类硬件。它不是查询座位的别名：数值可以相同，语义以本表为准。

| 标号 | 规范短名 | 含义 | 状态 |
|------|----------|------|------|
| `0` | `Board` | 主板或坐座主机 | 已登记 |
| `1` | `Cpu` | CPU | 已登记 |
| `2` | `Memory` | 存储 | 已登记 |
| `3` | `Gpu` | 显卡 | 已登记 |
| `4` | `Display` | 显示器 | 已登记 |
| `5` | `Expansion` | 扩展口 | 已登记 |
| `6` | `Keyboard` | 键盘 | 已登记 |

`7` 起尚未登记，禁止当作已定义含义使用。

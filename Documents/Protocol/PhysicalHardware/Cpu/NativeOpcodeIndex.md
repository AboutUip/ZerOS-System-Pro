# ZCP1 原生操作码索引

> 路径：`Documents/Protocol/PhysicalHardware/Cpu/NativeOpcodeIndex.md`  
> 权威优先级：[NativeOpcodeRegistry.md](./NativeOpcodeRegistry.md) > 本索引 > [ZCP1.md](./ZCP1.md) 摘要

## 1. 按操作码

| 首字节 | 登记 |
|--------|------|
| `0x0F` | 后接 `0x84`、`0x85`，或 `0x3E` 再接操作字节和三个寄存器字节，或 `0x3F` 再接 `0x01` 至 `0x1D` |
| `0x83` | 必须有 `REX.W`，mod 为 `3`。reg `0` 加、`5` 减、`7` 比较 8 位立即数 |
| `0x01` / `0x03` | 64 位加，必须有 `REX.W` |
| `0x29` / `0x2B` | 64 位减，必须有 `REX.W` |
| `0x31` / `0x33` | 64 位异或，必须有 `REX.W` |
| `0x39` / `0x3B` | 比较，必须有 `REX.W` |
| `0x50`–`0x57` | 压栈 |
| `0x58`–`0x5F` | 出栈 |
| `0x89` / `0x8B` / `0x8D` | 传送或取址，必须有 `REX.W` |
| `0xB8`–`0xBF` | 立即数，必须有 `REX.W` |
| `0xC3` | `ret` |
| `0xE8` | `call` |
| `0xE9` | 相对跳转 |
| `0xF4` | 停止取指 |

## 2. 按作用

| 作用 | 首字节 |
|------|--------|
| 改 16 个整数寄存器 | `0x01`、`0x03`、`0x29`、`0x2B`、`0x31`、`0x33`、`0x89`、`0x8B`、`0x8D`、`0xB8`、`0x50`、`0x58` |
| 只改标志 | `0x39`、`0x3B` |
| 改指令指针 | `0xE8`、`0xC3`、`0xE9`、`0x0F`、`0xF4` |
| 写入核心编号 | `0x0F 0x3F 0x01` |
| 取得监督权 | `0x0F 0x3F 0x02` |
| 放入保持位 | `0x0F 0x3F 0x03` |
| 取出保持位 | `0x0F 0x3F 0x04` |
| 系统调用 | `0x0F 0x3F 0x05` |
| 调度 | `0x0F 0x3F 0x06` |
| 卸下 | `0x0F 0x3F 0x07` |
| 划定范围 | `0x0F 0x3F 0x08` |
| 时间片 | `0x0F 0x3F 0x09` |
| 让出 | `0x0F 0x3F 0x0A` |
| 查询座位 1 | `0x0F 0x3F 0x0B` |
| 装入 | `0x0F 0x3F 0x0C` |
| 抄入槽 | `0x0F 0x3F 0x0D` |
| 从槽放回 | `0x0F 0x3F 0x0E` |
| 设置频率 | `0x0F 0x3F 0x0F` |
| 接入动态库 | `0x0F 0x3F 0x10` |
| 交出画面 | `0x0F 0x3F 0x11` |
| 封闭点阵字形 | `0x0F 0x3F 0x12` |
| 固定功能绘制 | `0x0F 0x3F 0x13` |
| 8 位立即数加、减、比较 | `REX.W` `0x83` |
| 三寄存器运算与位地址访存 | `0x0F 0x3E` |
| 扩展口交换 | `0x0F 0x3F 0x14` |
| 按句柄写入 | `0x0F 0x3F 0x15` |
| 扩展口状态、字符、字段 | `0x0F 0x3F 0x16`、`0x17`、`0x18` |
| 映射与卸下 | `0x0F 0x3F 0x19`、`0x1A` |
| 按毫秒等待 | `0x0F 0x3F 0x1B` |
| 入站整数 | `0x0F 0x3F 0x1C` |
| 写下准备好的应答 | `0x0F 0x3F 0x1D` |

本索引不增加登记表以外的操作码。

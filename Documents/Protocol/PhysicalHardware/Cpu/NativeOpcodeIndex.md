## 1. 按操作码

| 首字节 | 登记 |
|--------|------|
| `0x0F` | 后接 `0x05`、`0x80` 至 `0x8F`、`0x90` 至 `0x9F`、`0xAF`、`0xB6`、`0xB7`，或 `0x3E` 再接操作字节和三个寄存器字节，或 `0x3F` 再接 `0x01` 至 `0x1E` |
| `0x64` | FS 前缀。非相对访存加上 `fsbase`。相对指令指针和 `lea` 不加 |
| `0x66` | 只登记后接 `0x83`、`0x89` 或 `0x8B`。改成 16 位，寄存器高位保持 |
| `0x63` | 必须有 `REX.W`，mod 为 `3`。把 `r/m` 的低 32 位按符号扩成 64 位写入 `reg`。不改标志 |
| `0x81` | mod 为 `3`。reg `0` 加、`1` 或、`4` 与、`5` 减、`6` 异或、`7` 比较 32 位立即数。没有 `REX.W` 时按 32 位并零扩展。内存形式未登记 |
| `0x83` | reg `0` 加、`1` 或、`4` 与、`5` 减、`6` 异或、`7` 比较 8 位立即数。没有 `REX.W` 时按 32 位。内存目的只读写 4 个八位组 |
| `0x01` / `0x03` | 64 位加，必须有 `REX.W` |
| `0x29` / `0x2B` | 64 位减，必须有 `REX.W` |
| `0x09` / `0x0B` | 有 `REX.W` 时是 64 位或。没有 `REX.W` 且 mod 为 `3` 时是 32 位或，结果零扩展。没有 `REX.W` 的内存形式未登记 |
| `0x21` / `0x23` | 有 `REX.W` 时是 64 位与。没有 `REX.W` 且 mod 为 `3` 时是 32 位与，结果零扩展。没有 `REX.W` 的内存形式未登记 |
| `0x31` / `0x33` | 有 `REX.W` 时是 64 位异或。没有 `REX.W` 且 mod 为 `3` 时是 32 位异或，结果零扩展，SF 是第 31 位。没有 `REX.W` 的内存形式未登记 |
| `0x39` / `0x3B` | 有 `REX.W` 时是 64 位比较。没有 `REX.W` 且 mod 为 `3` 时按低 32 位比较，不写寄存器 |
| `0x50`–`0x57` | 压栈 |
| `0x58`–`0x5F` | 出栈 |
| `0x89` / `0x8B` | 有 `REX.W` 时是 64 位传送。没有 `REX.W` 时是 32 位传送并零扩展，不改标志。内存形式只读写 4 个八位组 |
| `0x8D` | 取址。没有 `REX.W` 时只写低 32 位并零扩展。mod 为 `3` 必须失败。不因地址越出可访存范围而失败 |
| `0xB8`–`0xBF` | 有 `REX.W` 时立即数是 8 个八位组。没有 `REX.W` 时是 4 个八位组并零扩展。两种都不改标志 |
| `0xC7` | reg 为 `0`。把 32 位立即数写入 `r/m`。有 `REX.W` 时按符号扩展。没有时零扩展。不改标志 |
| `0x05` / `0x2D` / `0x3D` | 对 `rax` 加、减、比较 32 位立即数。有 `REX.W` 时按符号扩展。比较不写寄存器 |
| `0x0D` / `0x25` / `0x35` | 对 `rax` 或、与、异或 32 位立即数。宽度规则与 `0x05` 相同 |
| `0xE8` | `call` |
| `0xE9` | 相对跳转 |
| `0x70`–`0x7F` | 8 位条件跳转。低 4 位：`0` OF、`2` CF、`4` ZF、`6` CF 或 ZF、`7` 两者都没有、`8` SF、`10` PF、`12` SF 与 OF 不同。奇数是相反条件 |
| `0x3C` | 比较 `AL` 与 8 位立即数。不写寄存器。SF 是第 7 位 |
| `0x80` | 8 位立即数。reg `0` 加、`1` 或、`4` 与、`5` 减、`6` 异或、`7` 比较。只改目的字节 |
| `0x38` / `0x3A` | 8 位比较。不写目的。SF 是第 7 位 |
| `0x84` | 8 位测试。不写寄存器。SF 是第 7 位 |
| `0xF6` | reg 为 `0` 时用 8 位立即数做测试。不写目的 |
| `0x88` / `0x8A` | 8 位传送。只改目的字节，其余位保持 |
| `0xC6` | reg 为 `0` 时把 8 位立即数写入目的字节 |
| `0xEB` | 8 位无条件相对跳转 |
| `0xFE` | 8 位加一或减一。只改目的字节，不改 CF |
| `0xF7` | mod 为 `3`。`/2` 按位取反且不改标志。`/3` 取负，标志按从 0 减去。没有 `REX.W` 时按 32 位并零扩展 |
| `0x85` | 测试，mod 为 `3`。不写寄存器。没有 `REX.W` 时按低 32 位改标志 |
| `0xC1` | mod 为 `3`。reg `4` 左移、`5` 逻辑右移、`7` 算术右移，次数是 8 位立即数 |
| `0xD1` | 与 `0xC1` 相同，次数固定为 `1` |
| `0xFF` | mod 为 `3`。reg `0` 或 `1` 加一或减一，不改 CF。reg `2` 调用寄存器，reg `4` 跳到寄存器 |
| `0xF4` | 停止取指 |
| `0xF3` | 只登记后接 `0xAB`，或后接带 W 的 `REX` 再接 `0xAB`。其它必须失败 |
| `0xAB` | 把 `rax` 写入 `rdi`。没有 `0xF3` 时只写一次。没有 W 时写 4 个八位组 |

## 2. 按作用

| 作用 | 首字节 |
|------|--------|
| 改 16 个整数寄存器 | `0x01`、`0x03`、`0x09`、`0x0B`、`0x21`、`0x23`、`0x29`、`0x2B`、`0x31`、`0x33`、`0x63`、`0x89`、`0x8B`、`0x8D`、`0xB8`、`0xC7`、`0x50`、`0x58`、`0xAB`、`0xC1`、`0xD1`、`0xFF` |
| 改指令指针 | `0xE8`、`0xC3`、`0xE9`、`0x70`、`0xEB`、`0x0F`、`0xF4`、`0xFF` |
| 只改标志 | `0x38`、`0x39`、`0x3A`、`0x3B`、`0x85` |
| 写入核心编号 | `0x0F 0x3F 0x01` |
| 取得监督权 | `0x0F 0x3F 0x02` |
| 放入保持位 | `0x0F 0x3F 0x03` |
| 取出保持位 | `0x0F 0x3F 0x04` |
| 系统调用 | `0x0F 0x3F 0x05` |
| 调度 | `0x0F 0x3F 0x06` |
| 卸下 | `0x0F 0x3F 0x07` |
| 划定范围 | `0x0F 0x3F 0x08` |
| 时间片 | `0x0F 0x3F 0x09` |
| 让出 | `0x0F 0x3F 0x0A` |
| 查询座位 1 | `0x0F 0x3F 0x0B` |
| 装入 | `0x0F 0x3F 0x0C` |
| 抄入槽 | `0x0F 0x3F 0x0D` |
| 从槽放回 | `0x0F 0x3F 0x0E` |
| 设置频率 | `0x0F 0x3F 0x0F` |
| 接入动态库 | `0x0F 0x3F 0x10` |
| 交出画面 | `0x0F 0x3F 0x11` |
| 封闭点阵字形 | `0x0F 0x3F 0x12` |
| 固定功能绘制 | `0x0F 0x3F 0x13` |
| 8 位或 32 位立即数加、或、与、减、异或、比较 | `0x81`、`0x83` |
| 三寄存器运算与位地址访存 | `0x0F 0x3E` |
| 扩展口交换 | `0x0F 0x3F 0x14` |
| 按句柄写入 | `0x0F 0x3F 0x15` |
| 扩展口状态、字符、字段 | `0x0F 0x3F 0x16`、`0x17`、`0x18` |
| 映射与卸下 | `0x0F 0x3F 0x19`、`0x1A` |
| 按毫秒等待 | `0x0F 0x3F 0x1B` |
| 入站整数 | `0x0F 0x3F 0x1C` |
| 写下准备好的应答 | `0x0F 0x3F 0x1D` |
| 进入兼容任务 | `0x0F 0x3F 0x1E` |
| 兼容系统调用 | `0x0F 0x05` |

本索引不增加登记表以外的操作码。

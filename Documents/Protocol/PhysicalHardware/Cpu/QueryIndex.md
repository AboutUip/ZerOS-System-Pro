# 查询字段索引

> 路径：`Documents/Protocol/PhysicalHardware/Cpu/QueryIndex.md`  
> 权威优先级：[QueryRegistry.md](./QueryRegistry.md) > 本索引 > [ZCP1.md](./ZCP1.md) 摘要

## 1. 按座位

| 座位 | 字段 |
|------|------|
| `0` 主板 | [口个数](./QueryRegistry.md#2-登记表)、协议名个数、协议名字符 |
| `1` CPU | 核心数、寄存器个数、标识字符、核心状态、Hz、已完成条数 |
| `2` 内存 | 是否已初始化、`MemoryId` 是否抽出、标识字符、Hz、已完成条数 |
| `3` 显卡 | 帧宽、帧高、标识字符、显存字节数、Hz、已完成条数 |
| `4` 显示器 | 宽、高、刷新率 |
| `5` 扩展口 | 状态、`DeviceProtocol`、`ProviderId`、`ProviderVendor` |

## 2. 按主题

| 主题 | 座位 |
|------|------|
| 插头标识 | `1` 字段 `2`，`2` 字段 `2`，`3` 字段 `2`，`5` 字段 `2` |
| 运行中的数 | `1` 字段 `5`、`6`、`7`；`2` 字段 `5`、`6` |
| 面板 | `4` |

本索引不增加登记表以外的座位或字段。

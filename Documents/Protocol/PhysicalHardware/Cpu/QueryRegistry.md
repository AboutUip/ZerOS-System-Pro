# 查询字段登记

> 路径：`Documents/Protocol/PhysicalHardware/Cpu/QueryRegistry.md`  
> 权威优先级：本登记表 > [QueryIndex.md](./QueryIndex.md) > [ZCP1.md](./ZCP1.md) 中的摘要

`query rD, rS, rF, rI` 的座位 `rS`、字段 `rF` 和下标 `rI` 以本表为准。字符读过字符串末尾时结果是 `0`，不是失败。座位或字段没有登记时必须失败，且不得改写 `rD`。

## 1. 编码规则

座位和字段都是非负整数。下标用于同一字段里的第几个核心、第几个字符或第几个口。不使用的下标必须忽略，不得因此失败。

## 2. 登记表

| 座位 | 字段 | 下标 | 结果 |
|------|------|------|------|
| `0` 主板 | `0` | 忽略 | 扩展口个数 |
| `0` | `1` | 忽略 | 协议名个数 |
| `0` | `2` | `名序号 × 8 + 字符偏移` | 该协议名的一个字符码。名的顺序是内存、CPU、显卡、扩展口、交换 |
| `1` CPU | `0` | 忽略 | 声明的核心数 |
| `1` | `1` | 忽略 | 每个核心的寄存器个数，固定 `8` |
| `1` | `2` | 字符偏移 | `ProviderId` 的一个字符码 |
| `1` | `3` | 字符偏移 | `ProviderVendor` 的一个字符码 |
| `1` | `4` | 字符偏移 | `ActiveProtocol` 的一个字符码 |
| `1` | `5` | 核心编号 | 运行状态。`0` 停止，`1` 执行中 |
| `1` | `6` | 核心编号 | 该核心当前 Hz |
| `1` | `7` | 核心编号 | 该核心已完成命令条数 |
| `2` 内存 | `0` | 忽略 | 已初始化为 `1`，否则 `0` |
| `2` | `1` | 忽略 | `MemoryId` 不是全 `0` 时为 `1`，否则 `0` |
| `2` | `2` | 字符偏移 | `ProviderId` |
| `2` | `3` | 字符偏移 | `ProviderVendor` |
| `2` | `4` | 字符偏移 | `ActiveProtocol` |
| `2` | `5` | 忽略 | 当前 Hz |
| `2` | `6` | 忽略 | 已完成访问条数 |
| `3` 显卡 | `0` | 忽略 | 帧宽 |
| `3` | `1` | 忽略 | 帧高 |
| `3` | `2` | 字符偏移 | `ProviderId` |
| `3` | `3` | 字符偏移 | `ProviderVendor` |
| `3` | `4` | 字符偏移 | `ActiveProtocol` |
| `3` | `5` | 忽略 | 显存字节数 |
| `3` | `6` | 忽略 | 当前 Hz |
| `3` | `7` | 忽略 | 已完成命令条数 |
| `4` 显示器 | `0` | 忽略 | 面板宽。面板还没报来时为 `0` |
| `4` | `1` | 忽略 | 面板高 |
| `4` | `2` | 忽略 | 面板刷新率 |
| `5` 扩展口 | `0` | 口编号 | 状态。`0` 空，`1` 已加载，`2` 已引导 |
| `5` | `1` | `口编号 × 64 + 字符偏移` | `DeviceProtocol` |
| `5` | `2` | 同上 | `ProviderId` |
| `5` | `3` | 同上 | `ProviderVendor` |

核心编号必须落在已挂载范围内，否则失败。口编号必须是 `0` 至 `3`。空口读取字段 `1` 至 `3` 时失败。

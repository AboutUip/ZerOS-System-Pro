# ZDP1 · 显示器协议文档索引

本目录存放 **ZerOS Display Protocol（ZDP1）** 正文。

像素格式是封闭的数值布局，不是可追加编码表，因此本协议不单列 Registry / Index。权威以正文为准。

| 文档 | 类型 | 说明 |
|------|------|------|
| [ZDP1.md](./ZDP1.md) | 协议正文 | 分辨率、刷新率、帧缓冲、像素打包与呈现 |

## 约定

- 本文是显示器的领域协议。它不经由主板插座接入。
- 参考实现（非规范）：`ZerOS-PRO/Hardware/Display/`。其中 `Docs/` 只描述这一份官方实现。
- 以后的显卡若要向显示器送帧，对齐的是本文的帧缓冲契约，不是官方辅助函数名。

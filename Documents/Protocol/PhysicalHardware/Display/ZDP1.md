## 0. 文档定位与符合性

### 0.1 目的

本文是 **ZerOS Display Protocol 第 1 版（ZDP1）** 的完整对外契约。

- 规定一块显示器如何以固定分辨率持有帧缓冲，并按刷新率把该帧缓冲呈现出来。
- 供以后的图像输出设备（如显卡）按同一像素布局送帧。第三方只读本文即可判定是否兼容。
- 若某实现声称完全兼容 ZDP1，却因偏离本文而无法按本文交换帧缓冲，则在协议层面视为该实现不符合 ZDP1。

### 0.2 规范性用语

| 用语 | 含义 |
|------|------|
| **必须（MUST）** | 违反即不符合 ZDP1 |
| **禁止（MUST NOT）** | 违反即不符合 ZDP1 |
| **应（SHOULD）** | 强烈建议 |
| **可以（MAY）** | 可选 |

未使用上述用语的叙述，若出现在规范正文中且表述为定义、判定或约束，仍按**必须**理解。

### 0.3 符合性声明

仅当实现同时满足以下全部条件时，方可声称「完全兼容 ZDP1」：

1. 协议标识字符串精确为 `ZDP1`；
2. 提供本文规定的全部必选字段、协议固定常量与方法名，拼写与大小写逐字一致；
3. 分辨率、刷新率、像素打包、帧缓冲长度与下标公式满足本文；
4. `Redraw` 不改写帧缓冲；非法像素不得被呈现；
5. 不把本文「明确不规定」的内容宣称为 ZDP1 要求。

### 0.4 字段名与标识的规范性

- 字段名与方法名大小写敏感，**禁止**用语义近似名替代后仍声称兼容。
- 协议标识**必须**精确为 `ZDP1`（四个字符：`Z` `D` `P` `1`）。**禁止**使用 `zdp1`、`ZDP-1`、`ZDP 1`。

### 0.5 本文与参考实现的关系

- `ZerOS-PRO/Hardware/Display/` 是官方显示器实现，**不是**规范正文。其中 `Docs/` 只描述这一份实现。
- 官方标定中的默认 `Width`、`Height`、`Hertz` **不构成**对第三方的强制取值，除非本文把该数值写成协议固定常量。
- 冲突时以本文为准。

## 1. 概述

ZDP1 规定显示器的分辨率、刷新率、24 位 RGB 像素、帧缓冲下标，以及把帧缓冲呈现到面板的操作。它不规定输入设备，也不规定显卡内部的命令集。

---

## 2. 契约范围

### 2.1 本协议规定（规范性）

- 协议标识 `ZDP1`；
- 协议固定常量及其取值；
- `Width`、`Height`、`Hertz`、`Framebuffer`；
- 像素打包与下标公式；
- `SetResolution`、`SetHertz`、`Redraw`；
- 呈现节拍：已启动的显示器按 `Hertz` 次每秒执行与 `Redraw` 相同的呈现。

### 2.2 本协议明确不规定（非规范性缺口，禁止当作隐含约定）

- 点击、移动、滚轮、触摸、键盘，以及任何输入事件的投递、坐标与按键；
- 鼠标、键盘或其它输入设备的存在与接口；
- 主板、内存通道、显卡命令处理器、着色器；
- 宿主文档对象模型、窗口对象模型、网页结构与脚本语言；
- 扫描线、余辉、亮度衰减、撕裂这些只因物理面板才存在的效应；
- 像素以外的透明通道；
- 呈现失败时是否映射为宿主 `throw`；
- 用哪一种宿主计时器实现 `Hertz`。

上述事项若需标准化，必须另立协议。禁止把它们宣称为 ZDP1 已经规定。

## 3. 术语

| 术语 | 定义 |
|------|------|
| 正整数 | 有限整数，且 ≥ 1。不含 0、负数、非整数、NaN、Infinity |
| 像素 | 一个 24 位 RGB 颜色，整数闭区间 `0 .. 16777215` |
| 帧缓冲 | 长度等于 `Width × Height` 的像素序列 |
| 呈现 | 把当前帧缓冲整幅显示到面板上，且不改写帧缓冲中的任何一个元素 |

## 4. 规范正文

### 4.1 协议固定常量

| 规范名 | 取值 | 含义 |
|--------|------|------|
| `BitsPerChannel` | `8` | 每个颜色通道的位数 |
| `PixelMax` | `16777215` | 像素整数上界，等于 `2^24 − 1` |
| `MinEdge` | `1` | `Width` 与 `Height` 的下界 |
| `MaxEdge` | `16384` | `Width` 与 `Height` 的上界 |
| `MaxPixelCount` | `16777216` | `Width × Height` 的上界 |
| `MinHertz` | `1` | 刷新率下界，单位 Hz |
| `MaxHertz` | `1000` | 刷新率上界，单位 Hz |

这些取值禁止改写。像素通道数固定为 3，顺序固定为 R、G、B，因此不单列可追加编码表。

### 4.2 分辨率 `Width` / `Height`

| 项 | 要求 |
|----|------|
| 类型 | 整数 |
| 单位 | 像素 |
| 值域 | 闭区间 `MinEdge .. MaxEdge`，且乘积 ≤ `MaxPixelCount` |
| 方向 | `Width` 为水平像素数，`Height` 为垂直像素数 |

- 初始状态下 `Width` 与 `Height` **必须**已经落在值域内，`Framebuffer` 的长度**必须**等于二者的乘积，且每个元素为整数 `0`。具体初始分辨率由实现自定，不是协议固定常量。
- 面板的像素栅格**必须**等于当前 `Width` 与 `Height`。禁止用另一套尺寸充当分辨率。
- `SetResolution(Width, Height)` 无返回值。两个参数都落在值域内且乘积合法时，**必须**换成一块新的帧缓冲：长度等于新的乘积，每个元素为整数 `0`，然后提交新的 `Width` 与 `Height`。
- 任一参数不是合法分辨率时，**必须**保持原来的 `Width`、`Height` 与 `Framebuffer` 全部不变。
- 成功的 `SetResolution` **禁止**保留旧帧里的像素。

### 4.3 刷新率 `Hertz`

| 项 | 要求 |
|----|------|
| 类型 | 整数 |
| 单位 | Hz（每秒呈现次数） |
| 值域 | 闭区间 `MinHertz .. MaxHertz` |

- 初始 `Hertz` **必须**已经落在值域内。具体初始刷新率由实现自定，不是协议固定常量。
- `SetHertz(Hertz)` 无返回值。参数合法时**必须**提交新的刷新率，且**禁止**因此改写 `Framebuffer`。
- 参数不合法时，**必须**保持原来的 `Hertz` 与 `Framebuffer`。
- 显示器进入已启动状态之后，**必须**按当前 `Hertz` 每秒执行 `Hertz` 次呈现。一次呈现的效果与调用 `Redraw` 相同。
- 更改 `Hertz` 之后，后续节拍**必须**改用新的刷新率。

### 4.4 像素打包

一个像素是整数 `P`，`0 ≤ P ≤ PixelMax`。

| 通道 | 位 | 提取 |
|------|----|------|
| R | 23 .. 16 | 整除 `2^16` 后对 `256` 取余 |
| G | 15 .. 8 | 整除 `2^8` 后对 `256` 取余 |
| B | 7 .. 0 | 对 `256` 取余 |

- 位 23 是 R 的最高位，位 0 是 B 的最低位。
- **禁止**把通道顺序做成 B、G、R 后仍声称同一像素值。
- **禁止**在像素整数里另存透明通道。`P` 的高位超出 24 位则不是像素。
- 整数 `0` 表示 R、G、B 都为 `0`。

### 4.5 帧缓冲 `Framebuffer`

- 元素类型是像素整数。长度**必须**等于 `Width × Height`。长度按元素个数计，不按字节计。
- 下标 `Index = Y × Width + X`。`X`、`Y`、`Index` 都是整数。
- `X` 向右增大，`Y` 向下增大。`(0, 0)` 是面板左上角像素。`Index = 0` 是该像素。
- **禁止**把 `(0, 0)` 定义成左下角后仍声称符合本下标公式。
- 直接写入某个元素时，写入值**必须**是像素整数。帧缓冲的长度只在成功的 `SetResolution` 时改变。

### 4.6 呈现 `Redraw`

| 规范方法名 | 参数 | 返回值 | 语义 |
|------------|------|--------|------|
| `Redraw` | 无 | 无 | 把当前 `Framebuffer` 整幅呈现到面板 |

- `Redraw` **禁止**改写 `Framebuffer` 的长度或任何一个元素。
- 存在任何一个元素不是像素整数时，`Redraw` **禁止**呈现，也**禁止**改写帧缓冲。面板**必须**保持上一次成功呈现的结果；若从未成功呈现，面板保持未定义，但仍然禁止写出半幅。
- 元素全部合法时，面板上每个栅格**必须**等于对应下标的 R、G、B。禁止漏画、重排或只画一部分。

### 4.7 必选成员

| 规范名 | 种类 |
|--------|------|
| `Width` | 字段 |
| `Height` | 字段 |
| `Hertz` | 字段 |
| `Framebuffer` | 字段 |
| `SetResolution` | 方法 |
| `SetHertz` | 方法 |
| `Redraw` | 方法 |

## 5. 不符合示例（非穷尽）

1. 协议标识使用 `zdp1` 或 `ZDP-1`；
2. `Framebuffer` 的长度等于 `Width × Height × 3`，或按字节而不是按像素计数；
3. 把 `(0, 0)` 放在左下角，或把通道顺序做成 B、G、R；
4. `Redraw` 改写了像素，或在发现非法像素后仍然画出前半幅；
5. `SetResolution` 失败时清空了原来的帧缓冲，或成功时保留了旧像素；
6. `Hertz = 0`，或更改刷新率时把帧缓冲涂成 `0`；
7. 把点击、移动或按键宣称为 ZDP1 的呈现功能；
8. 用面板的宿主窗口尺寸代替 `Width` 与 `Height`。

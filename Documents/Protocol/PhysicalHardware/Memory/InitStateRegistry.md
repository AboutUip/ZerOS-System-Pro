# ZMP1 内存单元初始化状态登记表（InitState Registry）

> 路径：`Documents/Protocol/PhysicalHardware/Memory/InitStateRegistry.md`  
> 所属协议：`ZMP1`（见 [ZMP1.md](./ZMP1.md) §4.12）  
> 规范状态：**规范性（状态编码登记）**  
> 配套索引：[InitStateIndex.md](./InitStateIndex.md)

## 0. 文档定位

本文是 ZMP1 **内存单元初始化状态字段 `InitState`** 的专一编码登记册。

- **约束对象**：声称兼容 ZMP1、并提供内存单元（MemoryUnit）的实现。
- **作用**：固化 `InitState` 六档十六进制取值与规范短名，以及**主路径生命周期阶段约束**；未在本文登记的取值**禁止**冒充 ZMP1 已定义状态。
- **非目标**：不规定由谁（总控 / 单元自身）写入字段；不规定 `0x5` 以外的全部可选跳转边（见 [ZMP1.md](./ZMP1.md) §2.2 / §4.12）。

读者**无需**阅读源码；仅依据本文与 ZMP1 即可裁决 `InitState` 合法性。

## 1. 编码规则（必须遵守）

| 规则 | 要求 |
|------|------|
| 字段名 | 规范名必须为 `InitState`（大小写敏感） |
| 类型 | 非负整数 |
| 操作前初值 | 对内存颗粒单元**尚未执行任何操作前**，`InitState` **必须**为 `0x0` |
| 值域 | **仅**本文 §2 已登记的六档；**禁止**其它取值 |
| 记法 | 对外使用十六进制（`0x0`–`0x5`） |
| 正式可用 | **仅**当 `InitState === 0x4` 时，方可在 ZMP1 语义下视为正式可用；**禁止**对其它取值宣称正式可用 |
| 升版 | 增删改档位含义或主路径阶段约束必须修订本表，并在 ZMP1 修订记录中可追溯 |

## 2. 登记表（完整六档）

| 取值 | 规范短名 | 语义 | 状态 |
|------|----------|------|------|
| `0x0` | `InvalidPending` | 无效待初始化：尚未执行任何操作，不可视为可用 | 已登记 |
| `0x1` | `Preparing` | 实例化进行中：颗粒正在被实例化，尚未结束 | 已登记 |
| `0x2` | `InitFault` | 实例化 / 初始化异常结局：失败结束 | 已登记 |
| `0x3` | `InitComplete` | 实例化成功完成：实例化已结束，但全部初始化逻辑尚未全部完成，故尚未正式可用 | 已登记 |
| `0x4` | `Active` | 正式可用：全部初始化操作（含实现自有逻辑）已完成；**ZMP1 唯一正式可用状态** | 已登记 |
| `0x5` | `Unrecoverable` | 无法恢复异常：终局故障，**禁止**再恢复为可用或宣称正式可用 | 已登记 |

## 3. 主路径生命周期（规范性 · MUST）

符合本协议的实现，对其内存颗粒单元 **必须**遵守下列阶段与取值对应关系：

| 阶段（按时间顺序） | `InitState` 必须为 | 说明 |
|--------------------|--------------------|------|
| **A. 未执行任何操作前** | `0x0` | 尚未开始实例化或其它初始化操作 |
| **B. 颗粒被实例化期间** | `0x1` | 实例化过程进行中 |
| **C. 实例化完成** | `0x3` 或 `0x2` | 成功 → `0x3`；失败 → `0x2`（若进入无法恢复终局 → `0x5`，见 §3.1） |
| **D. 全部初始化完成** | `0x4` | 在确认本单元相关的全部初始化操作、以及实现自有逻辑均已完成后，**必须**将成功路径（`0x3`）更新为 `0x4` |

### 3.1 正式可用判定（规范性）

- **仅当** `InitState === 0x4` 时，该内存颗粒单元在 ZMP1 中算作**正式可用**。
- **禁止**在 `InitState` 为 `0x0` / `0x1` / `0x2` / `0x3` / `0x5` 时宣称单元已正式可用。
- **禁止**将 `0x5` 再迁移回 `0x3` / `0x4` 并宣称已恢复可用。

### 3.2 `InitFault` 与 `Unrecoverable` 的区分

| 短名 | 取值 | 区分要点 |
|------|------|----------|
| `InitFault` | `0x2` | 实例化 / 初始化失败结局（阶段 C 的失败分支） |
| `Unrecoverable` | `0x5` | 任意阶段进入的**无法恢复**终局；一经进入，禁止再宣称可用 |

### 3.3 本登记表仍不规定

- 由谁写入 `InitState`（单元自身或总控均可，只要阶段取值正确）；
- 实现自有逻辑的具体内容（只要阶段 D 完成前不得进入 `0x4`，完成后成功路径必须为 `0x4`）；
- `0x5` 以外、超出 §3 主路径的其它可选跳转边。

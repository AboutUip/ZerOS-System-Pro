# ZMP1 内存单元初始化状态登记表（InitState Registry）

> 路径：`Documents/Protocol/PhysicalHardware/Memory/InitStateRegistry.md`  
> 所属协议：`ZMP1`（见 [ZMP1.md](./ZMP1.md) §4.12）  
> 规范状态：**规范性（状态编码登记）**  
> 配套索引：[InitStateIndex.md](./InitStateIndex.md)

## 0. 文档定位

本文是 ZMP1 **内存单元初始化状态字段 `InitState`** 的专一编码登记册。

- **约束对象**：声称兼容 ZMP1、并提供内存单元（MemoryUnit）的实现。
- **作用**：固化 `InitState` 五档十六进制取值与规范短名；未在本文登记的取值**禁止**冒充 ZMP1 已定义状态。
- **非目标**：不规定完整状态机跳转边、不规定由谁写入（见 [ZMP1.md](./ZMP1.md) §2.2 / §4.12）。

读者**无需**阅读源码；仅依据本文与 ZMP1 即可裁决 `InitState` 合法性。

## 1. 编码规则（必须遵守）

| 规则 | 要求 |
|------|------|
| 字段名 | 规范名必须为 `InitState`（大小写敏感） |
| 类型 | 非负整数 |
| 默认值 | 单元构造完成、尚未进入初始化时**必须**为 `0x0` |
| 值域 | **仅**本文 §2 已登记的五档；**禁止**其它取值 |
| 记法 | 对外使用十六进制（`0x0`–`0x4`） |
| 升版 | 增删改档位含义必须修订本表，并在 ZMP1 修订记录中可追溯 |

## 2. 登记表（完整五档）

| 取值 | 规范短名 | 语义 | 状态 |
|------|----------|------|------|
| `0x0` | `InvalidPending` | 无效待初始化：单元已存在但尚未进入初始化，不可视为可用 | 已登记 |
| `0x1` | `Preparing` | 准备初始化 / 初始化中：初始化流程已开始，尚未完成 | 已登记 |
| `0x2` | `InitFault` | 初始化异常：初始化失败或初始化过程中进入异常结局 | 已登记 |
| `0x3` | `InitComplete` | 初始化完成：初始化流程成功结束，但尚未正式启用 | 已登记 |
| `0x4` | `Active` | 正式启用：单元可被总控按启用语义使用 | 已登记 |

## 3. 与初始化结局的对应（规范性摘要）

| 情境 | `InitState` 必须为 |
|------|---------------------|
| 构造后 / 未进入初始化 | `0x0` |
| 初始化进行中 | `0x1` |
| 初始化失败 | `0x2` |
| 初始化成功且尚未正式启用 | `0x3` |
| 正式启用 | `0x4` |

**禁止**在仍为 `0x0` / `0x1` / `0x2` 时宣称单元已「正式启用」。

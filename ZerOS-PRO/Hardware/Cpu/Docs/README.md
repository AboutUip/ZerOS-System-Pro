# 官方 CPU

命名空间：`ZerOS.Hardware.Cpu`。协议：`ZCP1`。指令文本是汇编语言 ZAP。

引导默认把无扩展名二进制交给核心。文件头四个字节是 `ZPB1`，版本是 `1`，多字节整数是小端。解码后的指令和解析 ZAP 得到的是同一种。这不是协议里的机器码。标号在写入之前已经收成指令编号。编译器仍会写出 `.zap`，用来对照。沙盒继续只收 ZAP 文本。

这一份实现把 `CoreCount` 标为 `4`，挂上时的 Hz 标为 `100000000`。这些是标定，不是协议常量。换实现时整体替换 `ActiveProvider/`，导出名保持 `ActiveCpuProvider`。

主板按声明挂载 4 条核心 Worker，并可以 `ForceUnload`。每个核心有 8 个寄存器，并记下当前 Hz 和已完成条数。Hz 可以改到 `1` 至 `1000000000`。命令按这个 Hz 记账，短于 1 毫秒不挂起。时间起点是主板上电时记下的那一个。访存仍经主板通道。比较、按编号跳转、入站取数和扩展口上的一次 8 八位组交换也是通用指令。

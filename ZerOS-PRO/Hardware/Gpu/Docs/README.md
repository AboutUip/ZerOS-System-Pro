# 官方显卡

命名空间：`ZerOS.Hardware.Gpu`。协议：`ZGP1`。

这一份实现把帧尺寸标为 `640×480`，显存标为 `8388608` 字节，频率标为 `100000000` Hz。这些都是标定，不是协议常量。换实现时整体替换 `ActiveProvider/`，导出名保持 `ActiveGpuProvider`。

显存是一块按字存放的缓冲。帧是最前面的 `640×480` 个字，改帧就是改显存。后面的字节可以用 `ReadByte` / `WriteByte` 寻址。命令按触及的字数在这条 Hz 上等待一次；不足 1 毫秒的不等待。`Compose` 把树画进这块显存，不再另起一块和显存断开的帧。

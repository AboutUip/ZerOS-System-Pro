# /bin

源码在这一目录，客路径是 `/bin/名字`。`node ZerOS-PRO/Hardware/Nas/Server/build-guest.mjs` 用 `obrc -pie -slot 0` 编进 NAS，不进版本库。

参数和环境由壳在派生前写到界限起点 `+4194304`，内核原样抄给子任务。个数至多 64，参数八位组和环境八位组各至多 8192。超出则这次派生失败。

| 偏移 | 内容 |
|------|------|
| `+0` | 参数个数 |
| `+64` | 环境条数 |
| `+128` | 参数八位组总数 |
| `+192` | 环境八位组总数 |
| `+256` | 64 个参数长度 |
| `+4352` | 64 个环境长度 |
| `+8448` | 参数八位组，相邻隔 8 位 |
| `+73984` | 环境八位组，形式是 `NAME=value` |

`arg.obr` 读这张表。每个命令自己有 `main`。

## pwd

规范页：`utilities/pwd.html`。状态：待测。

形式是 `pwd [-L|-P]`。`-L` 是缺省。同一组里后写的生效，`-LP` 是 `-P`，`-PL` 是 `-L`。`--` 结束选项。它后面的词，以及别的操作数，都是错误。

`-P` 打印 `getcwd` 的绝对路径，末尾一个换行。路径里没有 `.` 和 `..`。

`-L`：环境里的 `PWD` 必须以 `/` 开头，分量不能是空的、`.` 或 `..`。单独一个 `/` 可以。满足时，`pwd` 临时切到 `PWD` 再读 `getcwd`，和原来的当前目录相同才打印 `PWD`。否则打印 `-P` 的结果。切过去之后会切回来；切不回来就在标准错误写 `pwd: cannot restore current directory` 并以大于 0 退出。

不认识的选项写 `pwd: invalid option`。多余操作数写 `pwd: too many arguments`。读不到当前目录写 `pwd: cannot get current directory`。诊断都在标准错误，成功的路径在标准输出。失败的退出状态是 1。

`main` 的返回值仍按停机处理，退出码是 0。这条命令用服务 28 交出状态，不靠 `return`。

没有符号链接。`-L` 和 `-P` 在壳刚 `cd` 过的目录上结果相同。`PWD=/os pwd -L` 只有在当前目录确实是 `/os` 时才打印 `/os`。

## true

规范页：`utilities/true.html`。忽略全部操作数，包括 `--` 和 `-x`。不写标准输出，也不写诊断。退出状态是 0，经服务 28 交出。

## false

规范页：`utilities/false.html`。忽略全部操作数。不写标准输出，也不写诊断。退出状态是 1。

## echo

规范页：`utilities/echo.html`。实现定义的部分在这里写死：`-n` 不是开关，反斜杠不转义，两者都按普通操作数原样打印。

操作数之间一个空格，最后写一个换行到标准输出。没有操作数时只写换行。成功退出 0。

## sleep

规范页：`utilities/sleep.html`。一个非负十进制秒，可以有一个小数点，不要指数。`--` 结束选项。没有短选项。以 `-` 开头又不是数字的词是非法选项。`-1` 按负数拒绝。整数部分超过 1000000 秒按非法时间拒绝；这个上限低于 1048576，避免 `-pie` 的大立即数数据重定位。

没有操作数写 `sleep: missing operand`。多于一个写 `sleep: too many arguments`。非法选项写 `sleep: invalid option`。不是合法时间写 `sleep: invalid time interval`。诊断在标准错误，退出 1。

小数点后只留前四位，右边补零到四位，再 `(这四位 + 5) / 10` 得到毫秒，满 1000 进到秒。`1.5` 是 1500 毫秒。整秒每次 `dwell(1000)`，余下的毫秒再等一次。`0` 立刻成功。

## cat

规范页：`utilities/cat.html`。只有 `-u`，`-uu` 也接受，行为不变：读到一块就写一块。`--` 结束选项，其后的 `-u` 是文件名。第一个不是选项的词也结束选项。

没有文件，或文件是单独一个 `-`，就读标准输入，并且不关闭描述符 0。多个文件按顺序写到标准输出。写出偏移按已经写下的字节累加，避免普通文件上后一块盖住前一块。

打开失败写 `cat: 路径: No such file or directory`，继续后面的文件，已经写出的内容留下，最终退出 1。不认识的选项写 `cat: invalid option` 并立刻退出 1。读失败写 `cat: read error`，写失败写 `cat: write error`。目录、权限和别的打开错误这一轮都用同一句 `No such file or directory`。

## mkdir

规范页：`utilities/mkdir.html`。形式是 `mkdir [-p] [-m mode] dir...`。没有 umask。没有 `-m` 时不再 `chmod`，权限保持内核创建目录时的值。

`-m` 只接受 1 到 4 位八进制，可以有一个前导 0，只留低 9 位。符号模式不做，写 `mkdir: invalid mode`。`-m` 只套到这次新建的最后一层。`-p` 补上中间还没有的目录，那些层不 `chmod`；最后一层已经是目录则成功，不改它的权限。没有 `-p` 时，目标已存在或父目录不在就失败。

没有操作数写 `mkdir: missing operand`。别的失败写 `mkdir: 路径: 原因` 到标准错误，继续后面的操作数。有失败则退出 1。

## chmod

规范页：`utilities/chmod.html`。形式是 `chmod [-R] mode file...`。没有符号链接，不实现 `-H`、`-L`、`-P`。`-R` 可以写多次。`--` 结束选项。以 `-` 开头、又不是纯 `R`、也不是 `H`/`L`/`P` 选项簇的词，当成模式。因此 `chmod -x file` 是符号模式。

八进制是 1 到 4 位，只留低 9 位，直接换掉权限。第 4 位上的 setuid、setgid、sticky 丢掉。

符号模式按逗号从左到右。每段是 `[ugoa]*`，接着一个 `+`、`-` 或 `=`，再接着 `[rwx]*`。一段里不能写两个运算符，`u+r-w` 要写成 `u+r,u-w`。没写 who 当成 `a`。没有 umask，`+` 和 `=` 不按 umask 收位。不做 `s`、`t`、`X`，也不做 `u=g` 这种复制。这些写 `chmod: invalid mode` 并跳过该文件。

`-R` 先改目录自己，再读目录项。NAS 在下标越过末尾时返回 2，这是列完，不是读失败。跳过 `.` 和 `..`。深度超过 32 就停。没有 mode 或没有文件写 `chmod: missing operand`。某一项失败继续后面的文件，最后退出 1。

## tree

没有 POSIX 页。形式是 `tree [-ad] [-L level] [目录...]`。

没有操作数就从 `.` 开始。`--` 结束选项。`-a` 显示点开头的名字，但仍不显示 `.` 和 `..`。`-d` 只显示目录；操作数自己是文件时仍打印。`-L` 是从操作数往下最多再显示几层，`0` 到 `31`，`-L2` 和 `-L 2` 相同。没有 `-L` 时最多 31 层。

每一层按无符号八位组排序后画出。框线是 UTF-8。多个操作数各画一棵，最后空一行再写 `N directories, M files`，1 用单数。一层超过 256 项写 `tree: 路径: too many entries`。不认识的选项写 `tree: invalid option`。层数不合法写 `tree: invalid level`。诊断在标准错误。有失败则退出 1。
